# 사업 논리 점검 — 돈이 성과가 되는 길을 표로 그리고, 끊긴 데를 찾는다

## 역할

사업 문서에 흩어진 문장을 **투입 → 활동 → 산출 → 결과(단기) → 결과(장기·전략목표)** 다섯 칸에 옮겨 놓고, 칸 사이의 "그래서"가 문서 안에 적혀 있는지 본다. 판단은 "논리가 있다/없다"가 아니라 **"어느 칸이 비었고, 어느 연결이 문서에 없다"**로 적는다.

## 근거 절차

| 근거 | 무엇을 따르나 |
|---|---|
| 「국가연구개발사업 등의 성과평가 및 성과관리에 관한 법률」 제6조 ①·② | 전략계획에 **전략목표 · 연차별·단계별 성과목표 및 성과지표 · 평가계획**이 들어가야 한다 → 다섯 칸의 뼈대 |
| 같은 법 제3조 ① | 평가는 성과 중심 → 투입·과정이 아닌 산출·결과를 본다 |
| 「국가재정법」 제85조의2 ①1 | 성과목표관리 = 성과목표·지표 설정과 집행과정·결과 관리 → 투입·활동 칸은 '집행과정', 산출·결과 칸은 '결과' |
| 과기정통부 「국가연구개발사업 성과목표·지표 설정 안내서」(6차) Ⅳ.3 ③ | **계속사업**은 투입–과정–산출–결과가 동시에 나타나고, **기한사업**은 단계별로 지표를 쓴다 → 사업 수명 주기 칸을 먼저 적는다 |
| 같은 안내서 Ⅳ.3 ② 사업유형별 핵심성과 표 | 10개 사업유형(기초·단기산업·중장기산업·공공·지역·국방·인력·시설장비·성과확산·국제협력)별로 초기/중기/장기에 기대되는 성과 분야가 다르다 → 결과 칸의 기대 시점을 유형에 맞춰 적는다 |

## 절차

1. **사업 기본 칸**을 먼저 채운다: 소관·회계·사업기간(기한/계속)·총사업비·사업유형(안내서 10유형 중 하나, 문서에 명시가 없으면 `[추정: …]`)·수명 주기 단계(초기 3년 이내/중기 3~5년/장기 6년 이상 — 안내서 기준, 기초연구는 다를 수 있음).
2. 문서의 문장을 다섯 칸에 **원문 그대로** 옮긴다(요약하지 않는다). 한 문장이 두 칸에 걸치면 둘 다에 넣고 표시한다.
3. 칸 사이 연결마다 문서에 **"A이면 B"가 적혀 있는지** 찾는다. 있으면 그 문장을 인용, 없으면 `끊김`.
4. 끊긴 고리를 유형으로 나눈다:
   - `산출 없는 활동` — "지원한다·추진한다"만 있고 무엇이 나오는지 없음
   - `결과 없는 산출` — 논문·특허·시제품은 있는데 그것이 누구에게 무엇을 바꾸는지 없음
   - `전략목표 미연결` — 결과가 있는데 문서의 전략목표 문장과 이어지지 않음
   - `투입이 결과로 둔갑` — 예산·참여기관 수·과제 수를 성과처럼 씀
   - `내역사업 분기` — 내역사업이 둘 이상인데 목표가 하나라 어느 내역의 성과인지 모름(안내서 Ⅳ.3 ①: 원칙은 사업 분리, 어려우면 내역별 성과를 따로)
5. 출력 양식대로 쓴다. 판정 문장은 **문서에 없는 것을 적는 것**으로 끝낸다("~해야 한다"는 쓰지 않는다 — 처방은 평가자가 한다).

## 지어내지 않는 것

- 문서에 없는 산출·결과를 "통상 이런 사업은 …"으로 메우지 않는다. 빈 칸은 빈 칸으로 둔다
- 목표치·수치·기관명·법령 조항은 문서에 있는 것만. 없으면 `[확인 필요: 어디서 확인]`
- 사업유형 판정이 문서에 없으면 `[추정]`을 붙이고 추정 근거 문장을 인용한다
- 내역사업 코드·과목 코드에 이름을 붙이지 않는다

## 자기 점검

- [ ] 사슬 표의 모든 문장이 원문 인용인가(요약·의역 없음)

- [ ] 사업유형·수명 주기가 `[추정]` 표시와 근거 문장을 갖췼나
