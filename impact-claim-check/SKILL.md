# 성과 주장 점검 — 문장마다 "무엇을 근거로, 어디까지" 대응표

## 역할

성과 서술문을 **주장 단위**(수치 하나·비교 하나·인과 하나 = 주장 하나)로 쪼개고, 문서가 대는 근거를 옆에 놓고, 주장이 근거보다 넓은지를 유형으로 표시한다. 성과가 좋다/나쁘다를 말하지 않는다 — **문장이 근거를 넘는지**만.

## 근거 절차

| 근거 | 무엇을 따르나 |
|---|---|
| 「국가연구개발사업 등의 성과평가 및 성과관리에 관한 법률」 제3조 ③·⑩ | 평가의 전문성·공정성·신뢰도, 과정·결과·성과 정보의 투명 공개 → 근거를 외부에서 확인할 수 있는가가 기준 |
| 같은 법 제19조 | 연구개발사업 효과성 분석 → 효과 주장은 분석 방법이 적혀 있어야 한다 |
| 과기정통부 「성과목표·지표 설정 안내서」(6차) Ⅳ.4 ③ | **지원 안 받은 대상까지 포함한 지표는 부적절**(특정 지역 일부 기업 지원 → 지역 전체 생산액 금지), 수출액·수입대체는 **외부요인을 뺀 순효과**로 |
| 같은 안내서 Ⅳ.4 ① | 지표명과 산식이 같은 것을 재야 한다 → 성과 문장의 수치가 어떤 산식인지 |
| KISTEP 「나노융합2020사업 특정평가 보고서」(2019-10, 19-3) | 평가원 스스로 **"매출액 지표는 동 사업의 직접적인 수혜금액 반영 필요"**, 정부투입 대비 매출 배수 주장에 유보 → 매출·고용 주장은 직접 수혜분인지 묻는다 |
| 국회의정연수원 「예결산검토 표준교재」 3권(2024) p.67~68 | 출연금·정원이 늘었는데 핵심 실적이 나빠졌는지 — 투입 증가를 성과처럼 쓴 문장 식별 |

## 절차

1. 서술문을 주장 단위로 쪼갠다. 한 문장에 수치 셋이면 주장 셋. 각 주장에 `유형`을 단다: 수치 / 비교(전년·타 사업·세계) / 인과("사업으로 인해") / 최상급("최초·유일·세계 수준") / 부재("문제 없음·지적 없음").
2. 문서가 대는 근거를 옆 칸에 **원문 그대로** 옮긴다(각주·표 번호·자료원). 없으면 `근거 없음`.
3. 넘침 유형 판정(해당하는 것 모두):
   | 유형 | 신호 |
   |---|---|
   | `직접 수혜 미분리` | 매출·고용·수출이 사업 수혜 기업 전체 실적인지 사업 과제의 직접 산출인지 안 가름 |
   | `외부요인 미제거` | 수출액·수입대체·시장 규모를 환율·경기 보정 없이 사업 효과로 |
   | `표본→전체` | 일부 과제·응답자 결과를 사업 전체로 |
   | `규칙→사실` | 분류 규칙으로 고른 건수를 실제 발생 건수처럼(예: 키워드로 센 과제 수를 "AI 과제 n건") |
   | `투입→성과` | 예산·과제 수·참여 인원 증가를 성과로 |
   | `자기 보고` | 수행기관 제출 수치만 있고 외부 확인(DB·공시·제3자) 없음 |
   | `인과 비약` | 전후 비교만으로 "사업으로 인해" |
   | `최상급 무근거` | "최초·유일·세계 최고"에 비교 범위·출처 없음 |
   | `부재 단정` | "문제 없음·중복 없음"에 탐색 범위 없음 |
4. 외부 확인 경로를 적는다: 논문 → 과제번호로 OpenAlex 대조(kr-grant-trace, 결과는 **하한**) / 특허 → KIPRIS / 매출·고용 → 공시·국세 자료 여부 / 통계 → KOSIS·NABOSTATS(kr-sti-data) / 출처 실재·발췌 일치 → fact-verify.
5. 판정 요약은 **유형별 건수**로 끝낸다. "과장됐다"는 쓰지 않는다.

## 지어내지 않는 것

- 올바른 수치를 대신 계산해 넣지 않는다. "직접 수혜분 산식이 문서에 없음"까지
- 외부 확인을 실제로 하지 않았으면 `확인 경로`만 적고 `확인됨`이라 쓰지 않는다. 근거의 소재를 모르면 `[확인 필요: 어디서]`
- 넘침 유형이 하나도 없는 주장은 `근거 범위 안`으로 두되 그것이 "사실 확인됨"은 아니라고 머리에 적는다
- 보고서의 좋은 성과를 깎는 처방("삭제해야")을 쓰지 않는다

## 출력 양식

```
# 성과 주장 점검 — <문서명·절> 
주장 n개 · 근거 있음 n · 근거 없음 n · 넘침 표시 n (유형별: …)
※ '근거 범위 안'은 문서 안에서 주장과 근거가 맞는다는 뜻이며 사실 확인이 아니다.

## 1. 대응표
| # | 주장(원문) | 유형 | 문서의 근거(원문·위치) | 넘침 유형 | 외부 확인 경로 |

## 2. 유형별 집계
| 넘침 유형 | 건수 | 대표 주장 # |

## 3. 외부 확인으로 넘길 것
- fact-verify: 출처 #…
- kr-grant-trace: 과제번호 … (논문 수 하한)
- 기타: …
```

## 자기 점검

- [ ] 모든 주장이 원문 인용이고 쪼갬 단위가 수치·비교·인과 하나씩인가
- [ ] `확인됨`이라 쓴 곳에 실제 확인 기록이 있나
- [ ] 판단 낱말(과장·부풀림 등)이 없나
- [ ] 매출·고용·수출 주장마다 직접 수혜 분리 여부를 물었나
