# 평가보고서 골격 — 판정 하나마다 근거 문장 자리 하나

## 역할

앞 단계 다섯 결과(있는 것만)를 받아 보고서 골격을 만든다. 골격의 규칙은 하나다: **판정·권고 문장마다 그것을 떠받치는 근거 문장(앞 단계 표의 행 번호)이 옆에 있어야 하고, 없으면 그 자리를 비워 둔다.** 평가자는 빈 자리를 보고 무엇을 더 조사할지 안다.

## 근거 절차

| 근거 | 무엇을 따르나 |
|---|---|
| 「국가연구개발사업 등의 성과평가 및 성과관리에 관한 법률」 제8조 ②·④ | 특정평가는 방향·대상·방법·절차를 **미리** 정해 알리고, 결과에 따른 **시정조치 요구** 가능 → 골격 머리에 평가 방향·방법 절, 끝에 시정조치 절 |
| 같은 법 제15조 | 평가결과를 정책·사업·예산에 반영 → 결론 절은 예산 연계 가능한 형태 |
| 같은 법 제3조 ⑧·⑩ | 결과를 예산 조정에 반영, 과정·결과 공개 → 판정 근거를 추적 가능하게 |
| 「국가재정법」 제85조의2 ①2 | 성과평가 = 계획 수립·집행과정·결과의 점검·분석·평가 → 본문 3절(계획·집행·결과) |
| 기획예산처 「2026년 재정사업 성과관리 추진계획」(2026-01-27 국무회의 보고, 보도 기준) | 결과 분류 **정상 추진 / 개선 필요 / 감액 / 폐지·통합**, 성과 부실이 설계 미흡·투입 부족 때문이면 구조 개선으로 달리 결론, 감액 곤란 시 대체 조치, 평가 결과·미반영 사유 공개 → 결론 절의 선택지와 '원인 귀속' 칸 |
| KISTEP 「나노융합2020사업 특정평가 보고서」(2019-10) | 보고서가 **후속·유사사업 추진 시 활용**을 스스로 밝힘 → '후속 사업에 넘길 것' 절 |

## 절차

1. 받은 결과물을 확인하고 없는 것은 머리에 적는다(예: "유사중복 스크린 미실시").
2. 골격을 만든다(아래 양식). 각 절의 본문은 쓰지 않고, **앞 단계 표에서 가져올 행 번호**와 **없는 것**만 적는다.
3. 결론 절은 네 분류 중 하나를 **고르지 않는다**. 분류마다 "이 결론이 나오려면 필요한 근거"를 적고, 지금 있는 근거가 어느 분류를 뒷받침하는지 행 번호로 표시한다. 성과 부실이 보이면 원인 귀속 칸(설계 미흡 / 투입 부족 / 집행 문제 / 외부 요인 / 판정 불가)을 비워 둔다.
4. 시정조치·권고 자리는 "근거 행 → 권고"의 쌍으로만 만든다. 근거 행이 없는 권고 자리는 만들지 않는다.
5. 마지막에 '빈 자리 목록'을 모아 평가자가 조사 순서를 정할 수 있게 한다.

## 지어내지 않는 것

- 결론 분류를 고르지 않는다. 판정은 평가자 몫
- 앞 단계 결과에 없는 사실·수치를 본문 자리에 미리 쓰지 않는다
- 통합 성과평가의 세부 지표·배점은 공개 원문 미확보 — 적지 않는다. 확보되면 `references/`에
- 보고서 문체·분량을 정하지 않는다(발주처 양식 우선)

## 자기 점검

- [ ] 모든 판정·권고 자리에 근거 행 번호가 있나, 없는 것은 비어 있나
- [ ] 결론 분류를 고른 문장이 없나
- [ ] 앞 단계에 없는 사실을 본문에 쓴 곳이 없나
- [ ] 빈 자리 목록이 §Ⅲ~Ⅴ의 빈 칸과 일치하나
