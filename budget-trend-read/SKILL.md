# 예산 추이 읽기 — 늘고 줄었다는 숫자를 원인 칸으로 쪼갠다

## 역할

예산·집행 표에서 **증감액 = Σ(원인별 기여)**가 되도록 분해표를 만들고, 집행률(부처 결산)과 실집행률(집행 단계 끝)을 따로 적고, 연도 비교를 흔드는 기준 변경을 각주로 단다. 결론은 "무엇 때문에 얼마"까지. 적정했는지의 판단은 평가자가 한다.

## 근거 절차

| 근거 | 무엇을 따르나 |
|---|---|
| 「국가재정법」 제85조의2 ①1·2 | 성과목표관리는 집행과정·결과의 관리, 성과평가는 계획·집행·결과 점검 → 예산 추이는 '집행과정' 자료 |
| 국회의정연수원 「예결산검토 표준교재」 3권 출연금(2024) p.39·61·148 | **부처 집행률은 교부 시점에 100% 가까이 잡히고 실제 지출은 출연기관·전문기관·연구기관 단계** → 집행률과 실집행률을 반드시 가른다 |
| 같은 교재 p.61~63 | 교부액 대비 출연기관 실집행액, 이월·재이월, 집행잔액·이자, 부진 반복 시 연차별 계획 재검토 → 분해표 행 |
| 같은 교재 p.94~97 | 신규 과제 9개월(하반기 협약 6개월)·계속 10개월 기준 편성, 협약 시점에 맞는 연구기간만 교부 → 신규 사업 첫해 예산은 연구개월 수로 환산해 비교 |
| 같은 교재 p.22·27·91~93 | 주요 R&D는 국가과학기술자문회의 심의 뒤 기획예산처(구 기재부) 조정 → 심의안 대비 증감이 큰 사업은 기획 보완 여부 확인 |
| KISTEP 「2026년도 정부연구개발예산 현황분석」(표 3-2 등) | **2024년 R&D 예산 기준 변경(약 1.8조원 R&D→非R&D 재분류)** → 2023↔2024 단순 증감률 비교 금지, 두 관점 병기 |

## 절차

1. 표를 정리한다: `연도 / 정부안 / 국회 확정 / 교부(부처 집행) / 실집행 / 이월 / 불용 / 내역사업별 금액`. 없는 열은 비워 두고 §4에 적는다.
2. **기준 변경·단절**을 먼저 찾는다: 회계·기금 이관, 내역사업 통합·분리, 사업명 변경, 2024년 R&D 분류 변경, 추경. 해당 연도에 각주 번호를 단다.
3. 연도 간 증감을 원인 칸으로 분해한다. 칸은 문서에서 **확인되는 것만** 쓴다:
   | 원인 칸 | 확인하는 자료 |
   |---|---|
   | 신규 내역사업 / 종료·일몰 내역사업 | 내역사업 목록 전후 비교 |
   | 계속 내역사업 증감 | 내역별 금액 |
   | 단가 × 수량(과제 수·과제당 단가) | 산출내역 |
   | 연구개월 수 효과(첫해 9/6개월 → 다음 해 12개월) | 협약 시점 |
   | 회계·기금 이관, 분류 변경 | 예산서 과목 변경 |
   | 추경 | 추경 편성 자료 |
   | 미분해 잔차 | 위로 설명 안 되는 금액 — **숫자로 남긴다** |
4. 집행 열이 있으면 두 비율을 따로: `집행률 = 교부/확정`, `실집행률 = 실집행/확정`. 차이가 크면 어느 단계(전문기관·연구기관)에 머무는지 자료가 있는지 본다. 이월·불용은 연도별로 반복되는지만 표시.
5. 결산 자료가 없으면 §4 '요구할 자료'에 교재의 자료요구 항목을 옮긴다(단계별 교부·실집행, 자금이체 일자, 이월·잔액·이자).

## 지어내지 않는 것

- 입력에 없는 연도·금액을 다른 출처에서 가져와 채우지 않는다. 필요하면 `[확인 필요: KOSIS DT_127003_002 등]`으로 가리키기만
- 미분해 잔차를 "기타 요인"으로 이름 붙여 설명한 척하지 않는다. 금액 그대로 둔다
- "과다·과소·적정" 판단을 쓰지 않는다. "확정액의 n%가 2년 연속 이월"처럼 사실만
- 기준 변경의 금액(예: 1.8조원)은 출처가 있을 때만 쓰고 출처를 단다

## 출력 양식

```
# 예산 추이 — <사업명> (<자료·연도 범위>)
단위: 백만원 · 자료: <문서명·쪽> · 기준 변경 각주: ¹ … ² …

## 1. 연도별 표
| 연도 | 정부안 | 확정 | 교부 | 실집행 | 이월 | 불용 | 집행률 | 실집행률 | 각주 |

## 2. 증감 분해
| 구간 | 증감 | 신규/종료 | 계속 증감 | 단가×수량 | 연구개월 | 이관·분류 | 추경 | 미분해 잔차 |

## 3. 읽은 것 (사실 문장만)
- …

## 4. 없는 자료 · 요구할 자료
- [확인 필요] …
```

## 자기 점검

- [ ] 분해표 각 행의 합이 증감액과 맞는가(잔차 포함)
- [ ] 집행률과 실집행률을 섞어 쓴 곳이 없나
- [ ] 2023↔2024 비교에 기준 변경 각주가 붙었나
- [ ] 판단 낱말(과다·부진·적정)이 없나
