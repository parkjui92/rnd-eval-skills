# 현장 시험 — 실제 예산 사업설명자료로 여섯 스킬 돌려 보기 (2026-11-22)

0.1.0을 올린 뒤 처음으로 실제 공개 자료로 여섯 스킬을 돌렸다. 0.1.0의 시범 실행은 안내서가 스스로 든 부적절 예시 4개뿐이었다.

## 이 시험이 보여 준 것과 보여 주지 못한 것

- 같은 모델에 스킬 없이 맡겨도 문서 안의 숫자 불일치는 대부분 잡는다. 스킬이 더하는 것은 **판정의 근거 절, 지표·주장 단위의 빠짐없는 표, 지어내지 않는 규율(미분해 잔차·[확인 필요])**이다. 발견 능력 자체를 크게 올리는 도구는 아니다.
- 원문 결함 가운데 일부는 스킬판보다 대조판이 먼저 잡았다(누적 목표 대 기존 실적). 그 점검을 지침에 넣었다.
- 시험 사업은 과기정통부 바이오 분야 2건뿐이다. 다른 부처·다른 유형(인력·시설·국제협력) 사업, 성과계획서·전략계획서를 함께 넣는 경우는 시험하지 않았다.
- 안내서 Ⅳ.3② 사업유형별 핵심성과 표의 내용은 여전히 스킬에 없다. 사용자가 그 표를 함께 주지 않으면 유형 적합(Q2) 판정은 `잠정`이다.
- 근거 절차의 법 조문·안내서 절·교재 쪽 번호는 0.1.0 작성 때 대조한 것이며 이번 시험에서 다시 대조하지 않았다.
- 입력 원문과 에이전트 결과물 전문은 이 저장소에 넣지 않았다(공개 자료이나 이용 조건을 따로 확인하지 않음). 위 결과는 요약이다.
