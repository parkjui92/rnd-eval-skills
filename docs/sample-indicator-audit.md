# 시범 실행 — indicator-audit (2026-10-20)

입력은 과기정통부 「국가연구개발사업 성과목표·지표 설정 안내서」(6차) Ⅳ.4가 **스스로 든 '보완이 필요한 측정방법 사례'**다. 안내서가 부적절하다고 밝힌 예시이므로, 스킬이 같은 결론에 닿는지 보는 회귀용이다. 실제 사업설명자료 1건 완주는 아직 하지 않았다(README 한계).

사업유형: `[추정] 공공기술개발` (예시 문맥) · 수명 주기: 미기재 · 지표 4개 · 질적 1(25%) · 투입·과정 1

## 2. 사업 단위
- 성과목표별 지표 수: 판정 불가(성과목표 미기재)
- 질적 지표 비율: 1/4 — 과반 권장 미달(Ⅳ.3④). 단 #1은 명목만 질적이고 산식은 투입 비율
- 투입·과정지표: 1(#3 산식 일부)

## 3. 판정 불가 — 없는 자료
- 성과목표 문장(Q1), 목표치와 설정 근거(Q7), 자료원·측정 주기 — 예시라 전부 미기재

## 4. 근거 표
| 판정 | 근거 | 적용한 문장(요지) |
|---|---|---|
| #1·#2 부적정 | 안내서 Ⅳ.4① | 측정방법(산식)이 지표명·개념에 부합하지 않는 경우 지양 — 안내서가 같은 두 예를 불일치 예시로 듦 |
| #3 부적정 | 안내서 Ⅳ.4② | 산식 세부항목이 투입·과정지표면 적절한 성과지표로 볼 수 없음 — 안내서가 같은 예를 듦 |
| #4 부적정 | 안내서 Ⅳ.4③ | 일부 기업만 지원하며 지역 전체 생산액을 지표로 삼는 것은 부적절 |
| 질적 비율 | 안내서 Ⅳ.3④, 법 제12조④ | 질적 지표 과반 권장, 표준지표에 질적 지표 포함 |

**결과**: 4건 모두 안내서의 판정과 같은 절에서 같은 결함을 짚었다. 스킬이 안내서를 베낀 것이 아니라 질문 Q5·Q6으로 도달하는지가 확인 대상이었고, 입력에 산식만 있어도 Q5·Q6은 답할 수 있었다. Q1·Q7은 입력이 비어 `판정 불가`로 남겨 두는 것이 맞다.
